# Lazuril

Lazuril is a static worldbuilding wiki for a homebrew Dungeons & Dragons 5.5e campaign setting.

For AI assistants and repository automation, start with [`AI_CONTEXT.md`](AI_CONTEXT.md). It is generated from the wiki search index and gives a fast map of the repo, important files, and lore pages.

To refresh it locally after content changes:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\update-ai-context.ps1
```
